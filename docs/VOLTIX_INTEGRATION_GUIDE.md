# Voltix & Toolbox Integration Guide

This guide establishes the architectural bridge, shared protocols, and maintainability standards between **Toolbox** and the **Voltix** application suite.

---

## 1. Ecosystem Alignment

Toolbox serves as the utility toolkit and offline processing engine for the Voltix ecosystem.

## 2. Shared Data Contracts

When integrating tools with Voltix workflows, data interchange should adhere to standard artifact schemas:

### A. Architectural Plans (`kind: 'json'`)
Floor plan data generated by the **Architecture Editor** is serialized as clean vector elements:
```json
{
  "version": "1.0",
  "units": "meters",
  "elements": [
    { "id": "wall-1", "type": "wall", "x": 100, "y": 100, "x2": 400, "y2": 100, "thickness": 8 },
    { "id": "door-1", "type": "door", "x": 250, "y": 100, "width": 40, "rotation": 0 },
    { "id": "room-1", "type": "room", "x": 100, "y": 100, "width": 300, "height": 200, "label": "Office" }
  ]
}
```

### B. Business & Quotation Takeoffs
The **Container Quote Builder** and **Invoice Generator** export structured bills of quantities:
```json
{
  "items": [
    { "description": "Wall Partitioning (Neoterm 50mm)", "quantity": 24, "unit": "sqm", "unitPrice": 45.0, "total": 1080.0 }
  ],
  "subtotal": 1080.0,
  "tax": 81.0,
  "total": 1161.0
}
```

## 3. WebRTC Spaces Integration

Voltix users can join collaborative Toolbox sessions via URL room codes:
- **URL Format**: `https://toolbox.domain/#spaces/<ROOM_CODE>`
- **Direct Artifact Deep Link**: `https://toolbox.domain/#spaces/<ROOM_CODE>/artifacts`
- **Signaling Compatibility**: Uses standard `y-webrtc` multi-room signaling matrices.

---

## 4. Maintenance & Evolution Checklist

When updating or adding capabilities to the platform:
1. **Never introduce telemetry or tracking** to tools labeled offline.
2. **Preserve backward compatibility** for saved artifact schemas in `localStorage`.
3. **Keep total dependencies minimal**: Prefer native Canvas / WebGL over bulky third-party CAD dependencies.
4. **Enforce clean code isolation**: No tool module should ever import another tool module directly; all cross-tool data flow passes through the Artifact Strip handoff system.
