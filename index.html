01 The Toolbox story

It started with a PDF.

A small task. A Google search. One unexpected beginning.

I needed to convert some files to PDF. So, like anyone would, I went looking for a PDF editor on Google.

Then a different thought showed up.

“Lemme just make one.”

02 Built with intention

The tool worked. The details mattered.

Toolbox began as something I wanted for myself: a direct, dependable way to get a job done without working around somebody else's idea of how it should feel.

I have no interest in writing code for its own sake. I care about building things with intention — thinking through the structure, the interaction, and the details until the result feels inevitable.

IntentThe standard behind every interaction

  • 02Clear in every state
  • 03Considered in every detail

03 One idea led to another

The base was there. The ideas kept coming.

Once the foundation was in place, the larger opportunity became clear. Useful tools across the web are often scattered between different interfaces, accounts, and standards.

A file converter became a coherent environment for the things worth doing every day — connected, consistent, and designed to work as one.

The idea becameToolbox.

04 Still being written

One place. More possibilities.

Toolbox is built on a simple conviction: useful software should also be exceptional software.

The next chapter is still being built, with the same standard applied to every interaction.
