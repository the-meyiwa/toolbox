About Toolbox

Toolbox is a collection of practical tools for everyday problems. Almost every tool runs entirely in your browser, so your files and text never leave your device. A small number — marked online on their card — have to ask a public service something, and those are the only ones that send anything anywhere.

They are the tools under Networking, which look up a domain, an address or a certificate; the Reference tools, which fetch the article, definition or passage you asked for; and a handful elsewhere — the weather, a map search and today's exchange rates. What leaves your device is the thing you typed into that tool, and nothing else.

The Code Playground downloads a language runtime the first time you use it — Python, SQLite, Lua or the TypeScript compiler — and then caches it. Code in those languages runs on your own machine and is never uploaded. The compiled languages are the exception: no browser can host a C or Swift toolchain, so that code is sent to a public build server to run, and the tool tells you before you press Run.

The core principle: many capabilities, few concepts, no manual required.

Saving and moving your work

Most tools are a one-shot job: open, do the thing, close the tab. Nothing is kept and nothing needs to be.

Some tools make something worth keeping — a tidied-up document, a converted file, a diagram, some code. Those show a Save button underneath. Saving puts a copy in this browser, on this device, and nowhere else. It is not an account and it is not a backup: clearing your browsing data removes it, and it will not appear in another browser or on your phone. Anything you would be sorry to lose should be downloaded as a real file.

The same strip offers Open in…, which hands what you are looking at straight to another tool that can take it — a CSV into the JSON formatter, a diagram into the code runner. Nothing is saved when you do that; it is a handover, not a filing decision.

Everything you have saved lives under Saved, which only appears once there is something in it. From there you can rename things, download one item or all of them as a single file, and open that file again later or on another machine.

In private browsing, or where storage is switched off, saving cannot keep anything past the tab. Toolbox says so at the point you try rather than pretending otherwise.
