About Toolbox

Toolbox is a collection of simple, practical tools for solving everyday problems. The vast majority of these tools run entirely offline in your browser, meaning your data never leaves your machine. A select few AI tools use free public APIs to bring you powerful capabilities without the need for subscriptions.

The core principle: many capabilities, few concepts, no manual required.
